**Домашнее задание №2 — доработка RAG-системы из первого занятия**

На этом занятии ваша задача — доработать ваше RAG-приложение, которое вы сделали на первом занятии через Replit.

Используйте GPT, Gemini, Claude, Grok, DeepSeek, GLM или любую другую LLM.  
Для выполнения домашнего задания вам нужен будет доступ к LLM через OpenRouter, создайте себе аккаунт и токен доступа — инструкция  
[https://docs.google.com/document/d/1C6HeBx775Rl\_\_\_5FYOyOreXNILmyu8qbB7Fq6fkvkMk/edit?tab=t.0](https://docs.google.com/document/d/1C6HeBx775Rl___5FYOyOreXNILmyu8qbB7Fq6fkvkMk/edit?tab=t.0)

**Что нужно сделать:**

— Возьмите вашу RAG-систему из первого занятия и доработайте её

— Добавьте hybrid-search:  
поиск должен работать не только через embedding, но и через поиск ключевых слов без использования LLM

— Объясните Replit, что нужно реализовать поиск ключевых слов обычным кодом через Python-библиотеки:  
BM25, TF-IDF или любые аналогичные библиотеки

— Система должна:

1. Находить ключевые слова в вопросе без LLM  
2. Выполнять поиск чанков по embedding  
3. Выполнять поиск чанков по ключевым словам  
4. Объединять результаты поиска

— Добавьте справа в интерфейсе отдельную панель “Логика работы RAG”, где должно выводиться:

1. Найденные ключевые слова  
2. 5 чанков, найденных через embedding-search по основному запросу  
3. Чанки, найденные по ключевым словам  
4. Финальный итоговый ответ AI

— Добавьте защиту от галлюцинаций:  
если релевантность найденных чанков слишком низкая или система не нашла подходящую информацию в базе знаний, AI должен отвечать:  
“К сожалению, я не нашёл информацию по этому вопросу в базе знаний”

— Для embedding используйте бесплатные модели без API и токенов

— Для ответов используйте бесплатные OpenRouter-модели через стандартный коннектор Replit

— При создании проекта приложите к Replit:

1. ТЗ  
2. txt-файл базы знаний

— Проведите 3–5 тестовых диалогов:

1. Обычные вопросы по базе  
2. Сложные вопросы  
3. Вопросы, на которые нет ответа в базе знаний
